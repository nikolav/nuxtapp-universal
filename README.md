# Nuxt 3 SSG Starter (SEO-Ready)

This is a **Nuxt 3 starter project**

---

## 🚀 Features

- Nuxt 3 (Vue 3 + Vite)

---

## 📦 Requirements

- **Node.js ≥ 18**
- npm / pnpm / yarn / bun (any works)

---

## ⚙️ Setup

Install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```
