# Nuxt 3 SSG Starter (SEO-Ready)

This is a **Nuxt 3 starter project** configured for:

- ✅ **Static Site Generation (SSG)** / prerendered HTML
- ✅ **SEO-first setup** (Nuxt SEO Kit: sitemap, robots, schema.org, OG)
- ✅ **SPA fallback routing** (for client-side navigation)
- ✅ **Headless-ready** (designed to consume a Laravel API)

Ideal for **marketing sites, landing pages, and content-driven apps** where performance and SEO matter.

---

## 🚀 Features

- Nuxt 3 (Vue 3 + Vite)
- Static prerendering via Nitro
- SEO best practices out of the box
- Clean routing using `pages/`
- Layout system (`layouts/default.vue`)
- Production-ready `.htaccess` for Apache hosting

---

## 📦 Requirements

- **Node.js ≥ 18**
- npm / pnpm / yarn / bun (any works)

---

## ⚙️ Setup

Install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```
